ВАЖНО ПРО config.js
-------------------
В пакет config.js НЕ включён намеренно.

EGE использует тот же Supabase-проект, что и OGE.
app.js понимает И window.EGE_CONFIG, И существующий window.OGE_CONFIG.

Поэтому самый безопасный вариант:
1. В рабочем репозитории Navigator_FIPI_OGE откройте текущий config.js.
2. Скачайте/скопируйте ЭТОТ ЖЕ config.js без изменений.
3. Положите его в корень Navigator_FIPI_EGE рядом с index.html.

НЕ присылайте содержимое config.js в чат.
НЕ используйте service_role / secret key.

Структура репозитория:
Navigator_FIPI_EGE/
  index.html
  styles.css
  app.js
  config.js        <- копия рабочего OGE config.js
  assets/
    brand-logo-fallback.svg

Если хотите тот же фирменный логотип:
- можно позже положить assets/brand-logo.png из OGE;
- пока автоматически используется безопасный fallback.

ПЕРВАЯ ПРОВЕРКА
---------------
После публикации:
1. Открыть сайт под VPN, если ваш dreamteamenglish.github.io без VPN сейчас не маршрутизируется.
2. Нажать «Войти».
3. Войти под своим административным email.
4. На главной должны появиться:
   - ADMIN · FULL
   - 901 units
   - 2634 заданий
5. Выбрать несколько разделов.
6. Нажать номер задания — должна открыться страница ФИПИ.

На этом этапе НЕ включать yandex_backup вручную.
